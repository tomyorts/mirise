# 07. 運営体制・制作ワークフロー

## 1. 体制と責務

| 役割 | 人員 | 稼働 | 責務 |
|---|---|---|---|
| 発行人(最終責任者) | 院長 | 月8〜12h | 全記事監修、インタビュー素材出し、症例選定、対外的な顔 |
| 編集長 | 1名(業務委託可、医療編集経験必須) | 月40〜60h | 企画、品質管理、進行管理、ライター採用・教育、KPI運用、この文書群の維持 |
| 医療ライター | 1〜2名 | 月5〜7本 | インタビューの構成・執筆(ゼロからの外注執筆は禁止) |
| 第二監修医 | 勤務医 or 提携矯正医 | 月4h | 院長執筆分の相互監修、ダブルチェック |
| コンプラ顧問 | 外部(医療広告に明るい行政書士/弁護士) | 月2〜4h | 公開前確認、四半期棚卸し、有事対応 |
| SEO/GEO | 外部パートナー | 月10〜20h | 技術監査、構造化データ、引用モニタリング |
| デザイナー | スポット | 立ち上げ+月数h | テンプレート、図版、症例写真の表示ルール |
| 開発 | 既存リソース | 立ち上げ+保守 | サイト実装、CMS、計測(02章・08章の仕様) |

### 採用の優先順位と妥協禁止ライン
1. **編集長が最重要。** 医療メディアの編集経験(できれば歯科・医科の広告審査経験)を持つ人を、報酬を上げてでも確保する。ここで妥協するとこのパッケージ全体が機能しない
2. ライターは「医療取材ができる」ことが条件。SEOライター出身の量産型は不可
3. コンプラ顧問は着手前に契約(着手条件。README参照)

## 2. 記事制作パイプライン(標準リードタイム: 3週間/本)

```
[企画] 編集長: 05章の計画 or FAQマイニングからテーマ確定、構成案作成
   ↓
[取材] 院長インタビュー録音30〜60分(編集長が構成案ベースで質問)
   ※院長の稼働を最小化する要。書かせない、話させる
   ↓
[執筆] ライター: 録音+出典資料から初稿(06章1節の型に準拠)
   ↓
[編集] 編集長: 構成・型・内部リンク・定型ブロックの確認
   ↓
[監修] 院長(or第二監修医): 医学的正確性の全文確認 → CMSに確認日記録
   ↓
[コンプラ] 04章チェックリストA/B/C実施 → レビュー記録に記入
   ↓
[公開] ステージング確認(構造化データ・CWV)→ 本番公開
   ↓
[更新] 四半期棚卸し(04章5節)+ Search Console/引用データに基づく改稿
```

- 監修とコンプラは**直列**(監修済みの版に対してコンプラをかける。順序を崩さない)
- 院長インタビューは月1回×2〜3時間にまとめ録りし、3〜5本分の素材を一度に確保する

## 3. 週次・月次の運用リズム

| リズム | 内容 |
|---|---|
| 週次(30分) | 編集長+院長: 進行確認、監修待ち解消、FAQネタ共有(カウンセリングで出た質問) |
| 隔週 | 記事公開2本(W6以降) |
| 月次(60分) | KPIレビュー(08章の月次レポート)、引用モニタリング結果、翌月の企画確定 |
| 四半期 | 全記事棚卸し(04章)、コンテンツ計画の改訂、体制・予算の見直し |

## 4. 予算計画(月次・目安)

| 項目 | 月額 |
|---|---|
| 編集長(業務委託) | 25〜40万円 |
| ライター(2〜3万円/本 × 5〜7本 ※医療単価) | 15〜20万円 |
| コンプラ顧問 | 5〜10万円 |
| SEO/GEOパートナー | 10〜15万円 |
| デザイン・図版(スポット) | 3〜5万円 |
| インフラ(Vercel/CMS/ツール) | 2〜3万円 |
| **合計** | **60〜93万円** |

- 立ち上げ一時費用(サイト開発・デザイン・撮影): 150〜300万円
- 12か月総投資: 約900〜1,400万円 → 回収ライン: 難症例成約 累計10件+SO収入+指名検索資産(00章)
- **撤退・縮小判断**: 08章の判断ルールに従う(感情ではなく事前に決めた基準で)

## 5. ツールスタック

- 制作管理: Notion or GitHub Projects(記事ステータス=パイプラインのステージ)
- 監修記録: CMS内フィールド+月次でCSVエクスポートして保全
- 録音・文字起こし: 院内で許可した録音デバイス+文字起こしツール(患者情報を含む録音は扱わない。インタビューは一般論と匿名化済み症例のみ)
- 引用モニタリング: スプレッドシート(06章6節)

## 6. リスクと引き継ぎ

- 編集長の離脱に備え、本ドキュメント群+CMS上のワークフローを「属人化しない仕組み」として維持する(更新は編集長の職務)
- 院長が多忙で監修が2週間以上滞留した場合: 公開を止める(未監修公開は絶対にしない)。滞留が常態化したら記事ペースを落とす判断を月次で行う
