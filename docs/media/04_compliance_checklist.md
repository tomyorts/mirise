# 04. 医療広告コンプライアンス運用マニュアル

前提(00章9節): 本メディアは医療機関が運営し自院への導線を持つため、**全ページを医療広告規制(医療法・医療広告ガイドライン)の対象とみなして運用する。** 加えて景品表示法・薬機法・不正競争防止法にも配慮する。

## 1. 公開前チェックリスト(全記事必須)

記事をCMSで「公開」に進める前に、編集長→監修医→コンプラ担当の3段階で以下を確認し、CMSの `reviewStatus` を更新する。

### A. 禁止表現(1つでも該当したら公開不可)

- [ ] 治療内容・効果に関する患者の体験談・口コミを含んでいない(引用・SNS埋め込み・「患者さんの声」を含む)
- [ ] 比較優良表現がない: 「日本一」「最高」「最先端」「他院より」「トップクラス」「◯◯なら当院」
- [ ] 誇大・保証表現がない: 「必ず」「絶対」「安全です」「後戻りしません」「痛くありません」「誰でも」
- [ ] 誘引目的の費用強調がない: 「今なら」「キャンペーン」「モニター価格」「期間限定」
- [ ] 「保険で安く矯正できる」等、保険適用を誘引に使う表現がない(適用条件の正確な説明はよい)
- [ ] 公序良俗違反・他院の誹謗中傷・「◯◯という治療は危険」型の恐怖訴求がない
- [ ] ランキング・おすすめ医院・医院リストを含んでいない

### B. 必須記載(該当する記事のみ・欠けたら公開不可)

- [ ] **自由診療に言及**: 定型ブロック(治療名/費用総額目安と内訳/標準的な期間・回数/保険適用外の旨/主なリスク・副作用)を挿入済み
- [ ] **ビフォーアフター写真・症例**: 02章2.2の全項目(治療内容・期間・回数・費用・リスク・副作用)が同一ページに、本文と同等の視認性で記載済み。折りたたみ・極小フォント・別ページ送りにしていない
- [ ] **未承認機器・適応外使用に言及**: 未承認である旨/入手経路/国内の承認医薬品等の有無/諸外国における安全性等に係る情報を記載済み
- [ ] **限定解除4要件**: ①問い合わせ先(電話・フォーム)の明記 ②自由診療の内容・費用 ③リスク・副作用 ④読者が自ら求めて閲覧するウェブページである(ポップアップ・リスティング広告のLPにこの記事を使わない)
- [ ] **効果に個人差がある旨**の記載(治療効果に言及した全記事)

### C. 信頼性・その他

- [ ] 執筆者・監修者が実名+資格で表示されている
- [ ] 監修医が全文を確認し、確認日がCMSに記録されている
- [ ] 医学的主張すべてに出典(ガイドライン・論文・公的資料)がある
- [ ] 症例写真の書面同意を取得済みで、同意書番号がCMSに記録されている
- [ ] 費用の数字がdisclosureBlockマスタ(02章)と一致している
- [ ] 統計・数字の出典と時点(「20XX年時点」)が明記されている

## 2. NG→OK書き換え辞書(執筆時に参照)

| NG表現 | 問題 | OK表現 |
|---|---|---|
| 「当院の矯正は痛くありません」 | 保証・虚偽のおそれ | 「痛みの感じ方には個人差があります。一般に装置調整後2〜3日は圧痛が出やすく、〜」 |
| 「最新のデジタル矯正で失敗しない」 | 最上級+保証 | 「3Dシミュレーションでは、歯の移動計画を事前に可視化できます。ただし予測と実際の歯の動きには差が生じることがあり、〜」 |
| 「患者様から『人生が変わった』と喜びの声」 | 体験談 | (掲載しない。症例解説の「医師の考察」で客観的経過を記述する) |
| 「サージェリーファーストなら治療期間が半分に」 | 効果の断定・比較 | 「サージェリーファーストは、術前矯正を省略または短縮するため、従来法より全体の治療期間が短くなる場合があります。適応には条件があり、〜」 |
| 「顎変形症は保険で安く治せます」 | 誘引目的の費用訴求 | 「顎変形症と診断され、指定医療機関で外科手術を前提とした矯正を行う場合、健康保険が適用されます。適用には次の条件があります」 |
| 「都内屈指の症例数」 | 比較優良 | 「当院では20XX年〜20XX年に外科矯正をXX例実施しました」(事実+期間) |
| 「放置すると顎関節症や胃腸障害の原因に」 | 恐怖訴求(因果の断定) | 「不正咬合と顎関節症状の関連は報告されていますが、因果関係は個別の診断が必要です(出典)」 |

## 3. SNS・LINE運用ルール

- 公式SNS・LINE配信・YouTube概要欄も**広告として同一基準**で運用する(体験談リポスト禁止、症例投稿は限定解除記載をリンク先でなく投稿内で完結)
- 患者からのポジティブなメンションに「ありがとうございます」以上の引用・増幅をしない(体験談の間接掲載になる)
- インフルエンサー・PR案件は受けない(ステマ規制+体験談規制の二重リスク)

## 4. レビュー記録フォーマット(CMS or スプレッドシート)

| 記事ID | 版 | 監修医確認日 | 監修医署名 | コンプラ確認日 | 確認者 | チェックリスト版 | 指摘と対応 |
|---|---|---|---|---|---|---|---|
| art-001 | v1.0 | 2026-08-01 | ◯◯ | 2026-08-03 | ◯◯ | v1 | 費用表記を幅表示に修正 |

- 保存期間: 無期限(行政照会・訴訟対応の証跡)
- 記事の重大更新(医学的内容・費用の変更)は新しい版として再レビュー

## 5. 四半期棚卸し手順

1. 全公開記事のリストをCMSから出力
2. 各記事について: 医学的内容の最新性 / 費用の現行性 / リンク切れ / ガイドライン改定の影響 を確認
3. 修正 or 「最終レビュー日」だけ更新(内容が現行のままの場合)or 非公開化(役目を終えた記事)
4. 医療広告ガイドライン・Q&A・関連通知の改定有無をコンプラ顧問が確認し、チェックリスト自体を改版

## 6. 有事対応(行政・患者からの指摘)

- 指摘受領 → 24時間以内に該当ページを一時非公開(判断に迷う場合も止める側に倒す)→ コンプラ顧問と協議 → 修正・再公開 or 削除 → 経緯を記録
- 保健所等からの照会には、監修記録・同意書・出典リストを即提出できる状態を常に維持する(4節の記録がそのまま防御資料になる)
