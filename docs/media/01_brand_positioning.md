# 01. ブランド・ポジショニング決定書

## 1. ブランド名(決定案)

**正式名称: 矯正治療の意思決定ガイド「キョウセイの前に」**

- 英語表記(将来のB2B・教育展開用サブブランド): **Ortho Decision Lab**
- 運営者表記(全ページフッター・運営者情報ページ): 「運営: ミライズ矯正歯科南青山」

### 採用理由
- 患者の行動文脈(「契約する前に読む」「矯正 始める前」)と名前が一致し、検索・SNS・口頭で説明しやすい
- 「ポータル」「ナビ」「ランキング」の語感を排除し、意思決定支援というポジションを名前で宣言できる
- 医院名と切り離した独立ブランドにすることで、他院で治療する読者にも開かれた情報源として認知される(ただし運営元は必ず開示する)

### ドメイン要件
- 医院公式サイトとは別ドメインで独立取得(サブドメイン・サブディレクトリにしない)
- 候補の優先順: `kyousei-no-mae.jp` 系 > `orthodecision.jp` 系。取得可否を確認して30日以内に確定
- SSL、WHOIS代行、5年以上の長期登録(ドメインエイジと継続性のシグナル)

## 2. ポジショニングステートメント

> 矯正治療を「始めるかどうか」「誰に任せるか」を決めようとしている人が、
> 契約の前に読む、日本で最も透明性の高い意思決定支援メディア。
> 特に、顎変形症・外科矯正・再治療など「普通の矯正情報では答えが見つからない人」の最後の参照先になる。

### ポジショニングの3本柱
1. **難症例の一次情報**: 顎変形症・外科矯正・サージェリーファースト・咬合再建・再治療。日本語圏で患者向け一次情報が空白の領域を実名専門医が埋める
2. **意思決定の道具**: 質問チェックリスト、セカンドオピニオンの受け方、転院とお金。読者が「どこで治療しても」役立つ道具を渡す
3. **透明性そのもの**: 編集ポリシー・監修記録・利益相反・広告方針を公開し、規制順守を差別化に転換する

### やらないことの宣言(ブランドの境界線)
- 医院のランキング・おすすめ・比較はしない
- 口コミ・体験談を集めない、掲載しない
- 掲載料・紹介料・アフィリエイトを受け取らない
- 「当院なら治せます」という文脈で記事を締めない(適応外のケースを常に明記する)

## 3. トーン&マナー

| 項目 | 指針 | NG例 → OK例 |
|---|---|---|
| 語り口 | 診察室で専門医が図を描きながら説明する口調。断定できることは断定し、個人差があることは条件を示す | 「〜かもしれません」の乱発 → 「骨格性の下顎前突では、歯の移動だけで見た目を大きく変えることはできません」 |
| 不安の扱い | 不安を煽って行動させない。不安の正体を分解して言語化する | 「放置すると大変なことに」 → 「放置した場合に起こりうる変化は次の3つで、進行速度には個人差があります」 |
| 数字 | 期間・費用・頻度は幅と条件付きで必ず示す | 「費用は医院によります」 → 「自由診療の場合の総額はおおむね◯◯〜◯◯万円で、内訳は…」 |
| 自院への言及 | 「当院では」を主語にした宣伝をしない。症例解説など事実ベースの文脈でのみ登場させる | — |
| 読者の呼び方 | 「患者様」ではなく「あなた」「読者」。過剰敬語を避ける | — |

## 4. デザイン方向性

- **雰囲気**: 医学誌とガイドブックの中間。白基調・余白多め・バナーゼロ・ポップアップゼロ
- **信頼の可視化**: 全記事ヘッダーに執筆者・監修者の顔写真+資格、公開日/最終更新日、記事フッターに参考文献
- **図版**: 3Dシミュレーション画面・セファロ分析・術式の図解を自前で作る(ストックフォトの「白衣の外国人」は使わない)。図版はそのままAI検索・SNSで引用される資産になる
- **CTAデザイン**: ボタンは全サイトで固定2種のみ(「オンラインセカンドオピニオン」「難症例相談」)。色は本文と調和させ、点滅・追従バナーは禁止

## 5. 医院公式サイトとの役割分担(混線防止)

| | メディア「キョウセイの前に」 | 医院公式サイト |
|---|---|---|
| 目的 | 全国の難症例患者の意思決定支援、指名検索の創出、業界内評判 | 近隣集患、診療案内、予約 |
| SEO | 情報型・比較検討型クエリ(全国) | 「南青山 矯正」等ローカル+MEO |
| CTA | 意思決定ツール、有料SO、難症例相談 | 初診予約 |
| 相互リンク | 運営者情報→公式サイト、症例解説→公式の診療案内(nofollowにはしない。関係は開示済みのため) | 公式→メディアは「運営メディア」として1か所 |

**禁止**: 公式サイトのブログ記事とメディア記事の重複展開(カニバリと重複コンテンツの温床)。既存の公式ブログに情報型記事がある場合は、メディア側に統合し公式側はリダイレクトまたはnoindexで整理する。
