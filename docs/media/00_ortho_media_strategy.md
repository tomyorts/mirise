# ミライズ矯正歯科南青山 矯正メディア構想 戦略評議会レポート

作成日: 2026-07-06
対象: 経営判断用(院長・経営層)
性格: 忖度なしの戦略評価と実行計画

---

## 0. 結論(先に答え)

**やるべき。ただし「矯正歯科ポータル」としては絶対にやるな。「難症例・意思決定支援に特化した専門メディア」としてのみ、今やる価値がある。**

- 一般的な「マウスピースvsワイヤー」「矯正 費用 相場」で戦う汎用矯正メディアは、2026年時点で参入余地がほぼない。AI Overviewが一般論を吸収し、ゼロクリック化が進み、量産記事の価値は毀損済み。ここに投資するなら**やらない方がいい**。
- 一方、ミライズの実態(顎変形症・外科矯正・サージェリーファースト・咬合再建・デジタル矯正)は、**日本語圏で一次情報がほぼ存在しない領域**。ここはAI検索が「引用したくても引用元がない」空白地帯であり、実在の専門医が実名で書く一次情報は、E-E-A-T・YMYLの構造上、後発が模倣できない。
- 目的をPVではなく「**難症例相談・セカンドオピニオン・指名検索**」に置くなら、必要記事数は少なく(12か月で60〜80本)、少数精鋭体制で回る。これは「メディア事業」ではなく「**専門性の外部化=ブランド資産構築**」であり、広告費と違ってストックになる。
- 最初の一手: **編集ポリシーと監修体制の公開ページを作り、柱記事3本(顎変形症の保険適用判断/サージェリーファーストの適応と限界/矯正セカンドオピニオンの受け方)を院長実名で出す。** ランキングも口コミも掲載料も、未来永劫やらない。

## 1. 評議会の忖度ない意見

### 医療マーケティング担当
「矯正メディアを今から」と聞いた瞬間の第一印象は**5年遅い**。2018〜2022年に乱立した矯正アフィリエイトメディアはコアアップデートでほぼ全滅し、生き残ったのは医療機関運営・実名監修のものだけ。つまり逆説的に、**医療機関本体が実名で運営するメディアだけが生存者利益を取れる市場**になった。参入が遅いのではなく、参入資格が絞られた後の市場。ミライズは参入資格を持つ側にいる。ただし「南青山 矯正」のローカルSEOと混同しないこと。メディアは全国の難症例患者と業界内評判のためのもので、近隣集患は医院公式サイト+MEOの仕事。**役割を分けないと両方中途半端になる。**

### SEO/GEO担当
汎用キーワード(「インビザライン 費用」等)は、AI Overview+大手ポータル+アライナーメーカーで埋まっており、勝っても刈り取られる。狙うべきは:
1. **AIが答えを持っていないロングテール難症例クエリ**(「下顎前突 手術 矯正だけ」「サージェリーファースト デメリット 後戻り」「顎変形症 保険 マウスピース不可 なぜ」)
2. **意思決定・比較検討の"構造"クエリ**(「矯正 セカンドオピニオン 失礼」「矯正 転院 費用 精算」)
3. **AI検索への引用最適化(GEO)**: AIは「実名の専門家が、構造化された定義と数字と条件分岐で書いた文章」を引用する。抽象論やポエムは引用されない。定義文・表・FAQ・schema.org(MedicalWebPage / FAQPage / Physician)・更新日・出典明記を全記事で徹底すれば、記事数が少なくても引用シェアは取れる。
指名検索(「ミライズ矯正歯科」)の増加が最終KPIであり、これはAI時代でも唯一奪われない資産。

### 医療広告ガイドライン・法務担当
最大のリスクはコンテンツではなく**「メディアの体裁」**にある。このメディアはミライズが運営し自院への誘導導線を持つ時点で、広告該当性(誘引性+特定性)を満たし**全ページが医療広告規制の対象**と考えて設計すべき。「情報サイトだから広告じゃない」という抗弁は、運営元が医院である限り通らない前提で作る。したがって:
- 体験談・口コミの掲載は治療内容・効果に関するものは**不可**(省令で明確に禁止)。
- ビフォーアフターは限定解除要件+詳細な説明(治療内容・期間・費用・リスク・副作用)併記でのみ可。
- 「ランキング」「おすすめ医院」は比較優良広告として**一発アウト級**。やらないと決めているのは正しい。むしろこの制約が競合ポータルとの差別化になる。
- 自由診療は費用・期間・回数・リスクの併記を全該当ページでテンプレート化すること。
逆に言えば、**規制順守を「編集ポリシー」として公開すること自体が信頼の証明=コンテンツになる。**

### 矯正歯科経営担当
経営数字で見る。難症例・外科矯正の患者1人のLTVは自由診療矯正で100〜150万円、外科併用でも医院への貢献は大きい。**月2件の記事経由相談→成約1件でも年間1,200万円超**。メディア投資が月50〜80万円なら、12〜18か月でペイする算段は立つ。ただし条件が2つ:
1. **院長の時間を月8〜12時間、監修と執筆素材出しに確保できるか。** できないならやるな。外注ライター記事に名前だけ貸すメディアは、ブランドを毀損して終わる。
2. **相談枠の受け皿。** メディアが機能すると遠方・難症例相談が増える。オンラインセカンドオピニオン(自由診療として価格設定)の枠と運用を先に設計しておくこと。集めてから捌けないのが一番もったいない。

### 患者体験(PX)設計担当
難症例患者のインサイトは「情報が欲しい」ではなく「**自分の場合どうなのかが分からず、誰を信じていいか分からない**」。だからCTAは「無料相談はこちら!」ではなく、**意思決定を前に進める道具**にする: 質問チェックリストのダウンロード、カウンセリングで聞くべきことリスト、セカンドオピニオンの受け方ガイド、自分の状態を言語化するセルフ整理シート。道具を渡すメディアは広告臭が消え、「この医院は売り込んでこない」という体験自体がミライズの差別化になる。**他院に行く患者にも役立つ設計**にすることが、結局最強のブランディング。

### メディア収益化担当
はっきり言う。**このメディアは当面「儲からないし、儲けようとするな」。** 掲載料・アフィリエイト・広告枠は、信頼という唯一の資産を毀損する。収益はメディア外で発生する: ①自院の難症例成約 ②セカンドオピニオン料 ③12か月以降の教育・研修(歯科医師向けセミナー、デジタル矯正ワークフロー研修) ④B2B(メーカー共同研究・講演、ただし利益相反を開示)。メディア単体のPLを作ると判断を誤る。**医院PLの「マーケ費→ブランド資産」勘定**として管理すること。

## 2. 勝ち筋

1. **「日本で最も透明性の高い難症例矯正の一次情報源」ポジションの先取り。** 顎変形症・外科矯正・サージェリーファーストの患者向け一次情報は空白。ここで引用のデファクトを取る。
2. **実名・実在・実績のE-E-A-T三点セット。** 執筆・監修・症例・設備がすべて実在の医院に紐づく。アフィリエイターにもメーカーにも模倣不能。
3. **「売り込まないCTA」による逆張りブランディング。** 意思決定ツール配布+他院受診も肯定する編集方針が、広告だらけの矯正情報空間で際立つ。
4. **少数精鋭×深さ。** 月5〜7本の深い記事は、月30本の浅い記事に、AI検索時代は確実に勝つ。
5. **メディア→指名検索→公式サイト→相談の二段ロケット。** メディアは信頼形成装置、刈り取りは公式サイトとオンライン相談が担う。
6. **将来の教育事業の見本市。** 記事・症例解説・3Dシミュレーション解説がそのまま歯科医師向け教育コンテンツの品質証明になる。

## 4. 推奨サイト名・ブランド案

要件: ①医院名と別ブランド(独立した情報源として認知されるため) ②ただし運営元は明記(隠すと逆に信頼毀損+広告該当性は変わらない) ③「ポータル」ではなく「ガイド/ジャーナル」の語感。

| 案 | 名称 | 意図 |
|---|---|---|
| A(推奨) | **矯正治療の意思決定ガイド「キョウセイの前に」** | 「契約する前に読む」という患者の行動文脈そのもの。検索・SNSで語られやすい |
| B | **Ortho Decision(オルソディシジョン)** | 意思決定支援を直球で。将来のB2B/教育展開時にブランドを流用しやすい |
| C | **顎と歯並びの相談室 by ミライズ** | 難症例・顎変形症への特化を名前で宣言。ニッチ度最大 |

ドメインは医院公式とは別に独立取得し、フッターと運営者情報ページに「運営: ミライズ矯正歯科南青山」を明記。編集ポリシー・監修体制・利益相反(自院誘導があり得ること)を公開する。**この透明性ページ群はSEO/GEO/法務すべてに効く最重要ページ。**

## 8. 収益化モデル(順番を守ること)

1. **Phase 1(0〜6か月): 自院価値のみ。** 難症例相談・セカンドオピニオン(有料)・成約。メディア内マネタイズはゼロ。
2. **Phase 2(6〜12か月): 専門性の直接販売。** オンラインSOの体系化、講演・執筆・監修受託(受ける場合も利益相反を明示)。
3. **Phase 3(12か月〜): 教育・B2B。** 歯科医師向け研修(サージェリーファースト、デジタル矯正、咬合再建)、スタディグループ、メーカーとの共同コンテンツ(スポンサーシップは「広告」表記+編集独立を明文化)。
4. **恒久的にやらないもの: 医院掲載料、ランキング、アフィリエイト、口コミ課金。** これは収益化の選択肢ではなく、ブランドの自殺。

## 9. 医療広告・法務チェックリスト

**前提: 本メディアは運営元が医療機関であり自院導線を持つため、全ページを広告規制対象として設計する。**

- [ ] 体験談・口コミ: 治療内容・効果に関する患者体験談は掲載しない(広告規制で明確に禁止)。
- [ ] ビフォーアフター: 掲載時は治療内容・期間・回数・費用・主なリスク・副作用を同一ページで併記(限定解除要件)。加工・トリミングで誤認を生む写真は不可。
- [ ] 限定解除4要件の充足を該当ページでテンプレ化: ①問い合わせ先明記 ②自由診療の内容・費用 ③リスク・副作用 ④患者が自ら求めて入手する情報である形式。
- [ ] 比較優良表現の禁止: 「日本一」「最高水準」「他院より優れる」等は使わない。症例数等の実績は客観的事実+期間明示のみ。
- [ ] 誇大・保証表現の禁止: 「必ず治る」「後戻りしない」「安全です」は不可。効果には個人差・リスクを常に併記。
- [ ] 自由診療表記: 費用(総額目安と内訳)、標準的な期間・回数、公的保険適用外である旨を定型ブロックで全該当記事に。
- [ ] 保険適用(顎変形症等)の説明: 適用条件を正確に。「保険で安く矯正できる」的な誘引表現にしない。
- [ ] 未承認機器・薬機法: 装置・材料の未承認/適応外使用に触れる場合は、入手経路・国内承認の有無・諸外国の安全性情報を記載。
- [ ] 体験談規制のSNS波及: 公式SNS・LINE配信も広告として扱い、同一基準で運用。患者投稿のリポストも治療効果に関するものはしない。
- [ ] 「監修」の実態確保: 監修者が実際に全文確認した記録(日付・版)を社内保存。名義貸しをしない。
- [ ] 打消し表示: リスク併記は本文と同等の視認性(極小フォント・折りたたみ隠しは景表法・ガイドライン両面でNG)。
- [ ] 薬機法・景表法・医師法(遠隔での「診断」に踏み込まない。オンラインSOは「情報提供・意見」の建付けと同意書)。

## 10. AI検索時代のコンテンツ設計(GEO)

- **引用される文章の型**: 冒頭に定義文(「顎変形症とは、〜である」)→条件分岐(「〜の場合は保険適用、〜の場合は自由診療」)→数字(期間・費用・頻度)→出典。AIは曖昧な文章を引用できない。
- **FAQの徹底**: 実際の患者の質問(カウンセリング記録・LINEの質問)をそのままFAQ化。これは競合が持たない一次データ。
- **一意性のある一次情報**: 3Dシミュレーション画面の実例解説、術式選択の実際の判断過程、学会発表内容の患者向け翻訳。「この情報はここにしかない」状態がAIの引用を強制する。
- **エンティティ確立**: 院長・医院・メディアをschema.orgと外部プロフィール(学会、researchmap、公式サイト)で相互リンクし、ナレッジグラフ上の実在性を固める。
- **マルチモーダル**: 記事と同一内容の短尺動画・音声(院長本人の声)。AIモードは動画ソースも参照し、本人性の証明にもなる。
- **更新性**: 「最終更新日+何を更新したか」を明記。医療YMYLでは鮮度が引用条件になる。
- **測定**: AI Overview / ChatGPT / Perplexityで主要50クエリを月次で手動チェックし、引用有無を記録(GEOのランクトラッカーは未成熟なので原始的にやる)。

## 13. 経営判断サマリー

### 今やるならこの形
- 難症例・外科矯正・意思決定支援に特化した**独立ブランドの専門メディア**。運営元は透明に開示。
- 少数精鋭(編集長1+ライター1〜2+院長監修)、月5〜7本、深さ全振り。
- 収益は自院の難症例相談・有料SOから。メディア内広告収益はゼロで設計。
- 12か月・総投資800〜1,200万円を「ブランド資産の取得」として承認できるならGO。

### やらない方がいい形
- 汎用矯正キーワードの記事量産、AIライティング主体、外注丸投げ。
- ランキング・口コミ・医院掲載料・アフィリエイトを含むあらゆるポータル型。
- 院長の監修時間を確保しないままの見切り発車。
- メディア単体での短期黒字化を求めるPL設計。

### 最初の一手(今週やること)
1. 院長の月10時間のコミットを経営判断として確定する(これが無理なら計画自体を中止)。
2. ブランド名決定+ドメイン取得(A案推奨)。
3. **透明性ページ群(監修体制・編集ポリシー・広告方針)を最初のコンテンツとして書く。**
4. 柱記事3本の院長インタビューを録音する: ①顎変形症の保険適用判断 ②サージェリーファーストの適応と限界 ③セカンドオピニオンの受け方。
