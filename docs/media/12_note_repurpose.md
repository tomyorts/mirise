# 12. note転用ポリシー(コンテンツ・リパーパス)

「キョウセイの前に」の記事を note.com(医院公式アカウント)へ転用するときのルール。
下書きの実体は `apps/media/content/note/*.md`、投稿用のコピペページは監修チェックリストと同様にArtifactで共有する。

## 原則(必ず守る)

1. **監修確定済みの記事だけ**を転用する(`content/review.ts` で publish:true、または reviewStatus:'published')。
   未確定の数値・記述を外部媒体に出さない。
2. **全文転載しない**。1,200〜1,800字のダイジェストに再構成する。
   - 本サイト公開前に全文をnoteへ出すと、検索エンジンがnote側を「本家」と認識し、
     本サイトが重複コンテンツ扱いになるリスクがあるため。
   - note公開後に本サイトが公開されたら、note記事末尾に本サイト記事へのリンクを追記する。
3. **医療広告ガイドラインは本サイトと同一基準**: 断定・保証・最上級・比較優良の禁止、
   「個人差があります」の留保、体験談の捏造禁止、「当院なら」の誘導禁止(医院名は監修クレジットのみ)。
4. 数値は元記事の確定値のみ。noteのために新しい数値を作らない。
5. 各記事末尾に定型ブロック(監修クレジット+免責+本サイト予告)を必ず付ける。

## 下書きの形式(content/note/*.md)

```
# note用タイトル(質問形・32字以内)
hashtags: #歯列矯正 #顎変形症 ...(5個)
本文(Markdown。## 見出し3〜4個+費用とリスクの要約+まとめ)
---
定型ブロック(監修・免責・本サイト予告)
```

## 運用フロー(記事が新たに監修確定するたび)

1. Claudeがダイジェスト下書きを生成 → 校閲(広告表現・数値一致)→ `content/note/` にコミット
2. コピペ用Artifactページを再生成・更新(タイトル/本文/タグをワンタップコピー)
3. CEOがnoteに貼り付けて投稿(1本あたり約1分)。投稿間隔は1日1〜2本を目安
4. 本サイト公開後: note記事末尾に該当記事URLを追記(「全文はこちら」)

- 固定記事に編集ポリシーの要約(体験談を載せない理由・監修体制)を置くと信頼性が上がる
