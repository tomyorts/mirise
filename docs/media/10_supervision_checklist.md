# 10. 記事監修チェックリスト(要確認マーカー一覧)

監修者(富田大介 院長)向け。各記事に埋め込んだ **「要確認」** 箇所を機械抽出したものです。
本文中の数値・条件・断定表現のうち、**臨床的な裏取りが必要**なもの、または医院の運用に合わせて
確定が必要なものに付けています。

## 使い方
1. 記事ごとにチェックボックスを1つずつ確認し、**正しい数値・表現に確定**する(または「一般的にはこう表現する」に修正)。
2. 数値には**出典**(ガイドライン・論文・学会資料等)を添えると、記事の参考文献に反映できます。
3. すべて確定したら、その記事の `lib/articles.ts` の `reviewStatus` を
   `draft` → `reviewed`(監修済み)→ `compliance_checked`(広告審査済み)→ `published` と進めます。
4. `published` になった記事はドラフトバナーが消え、サイトの `noindex` 解除後に一般公開できます。

> ⚠️ 医療広告ガイドライン: 確定作業では **断定・保証・比較優良(No.1/最高/必ず治る 等)** を使わないこと。
> 「個人差があります」「報告により幅があります」等の留保を保つ(docs/media/04)。
