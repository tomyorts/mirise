## 前提となる意思決定(00章の結論)

- 「矯正歯科ポータル」ではなく**難症例・意思決定支援特化の専門メディア**として運営する
- ランキング・口コミ・医院掲載料・アフィリエイトは**恒久的に行わない**
- 全ページを医療広告規制の対象とみなして設計する
- 収益はメディア外(難症例相談・有料セカンドオピニオン→教育・B2B)で回収する

## 着手条件(これが満たせないなら開始しない)

1. 院長の月8〜12時間(監修・インタビュー)の確保
2. 医療広告に明るい外部コンプライアンス顧問の契約
3. 12か月・総額800〜1,200万円の投資承認
