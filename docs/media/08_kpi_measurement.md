# 08. KPI定義・計測実装仕様

原則: **PVと検索順位は主KPIにしない。** 見るのは「意思決定への貢献」と「医院への実利」。
オフラインコンバージョン(電話・来院)を拾う仕組みを初日から実装する。

## 1. KPIツリー

```
北極星: 記事経由の「質の高い相談」件数/月
├─ 成果KPI
│   ├─ 相談予約数(SO / 難症例 / 一般)
│   ├─ セカンドオピニオン実施件数
│   ├─ 成約数・成約率(相談→治療開始)
│   └─ 記事経由LTV(成約単価×件数)
├─ 質KPI
│   ├─ 相談フォームで記事名・具体的論点に言及した割合
│   ├─ 初診アンケート「選択肢を事前に理解していたか」(5段階)
│   └─ カウンセリング所要時間の変化(理解済み患者は短くなる)
├─ ブランドKPI
│   ├─ 指名検索数(「ミライズ矯正」「キョウセイの前に」)
│   ├─ 直接流入・再訪率
│   └─ AI引用数(主要50クエリ、06章6節)
├─ 中間KPI
│   ├─ LINE登録数 / チェックリストDL数
│   └─ 記事完読率(90%スクロール)・平均エンゲージメント時間
└─ 供給KPI
    ├─ 公開記事数 / 監修遵守率100% / コンプラ指摘ゼロ
    └─ 制作リードタイム(3週間以内)
```

## 2. 12か月目標値(月次トラッキング)

| KPI | 3か月 | 6か月 | 12か月 |
|---|---|---|---|
| 記事経由相談(質の高い相談) | 1件 | 3〜5件 | 8〜12件 |
| SO実施件数 | — | 2件 | 5件 |
| 成約率(難症例相談→治療) | — | 計測開始 | 30%+ |
| 指名検索(月間) | ベースライン計測 | +20% | +50% |
| LINE登録 | 20/月 | 50/月 | 80/月 |
| 患者理解度(初診アンケート) | 計測開始 | 3.5+ | 4.0+ |
| AI引用クエリ数(/50) | ベースライン | 5+ | 15+ |
| 公開記事数(累計) | 24 | 40 | 60〜80 |

## 3. 計測実装仕様

### 3.1 GA4イベント設計

| イベント名 | 発火条件 | 主要パラメータ |
|---|---|---|
| `article_read_90` | 90%スクロール+60秒以上滞在 | article_id, category |
| `checklist_download` | チェックリストDL完了 | article_id(流入元記事) |
| `line_register_click` | LINE登録ボタン | article_id |
| `consult_form_start` | 相談フォーム入力開始 | consult_type(so/complex/general) |
| `consult_form_submit` | 送信完了 | consult_type, first_article(初回接触記事), last_article |
| `cta_click` | 固定CTAクリック | cta_position, article_id |

- 初回接触記事: ファーストパーティCookie(またはlocalStorage)に初回LP記事IDを保存し、フォーム送信時にhiddenフィールドで送る(記事アトリビューションの根幹)
- コンバージョン設定: `consult_form_submit` / `checklist_download` / `line_register_click`

### 3.2 相談フォーム必須項目(質KPIの取得源)

1. 相談種別(SO / 難症例 / 一般)
2. **「このサイトのどの記事がきっかけになりましたか」**(記事タイトルのサジェスト付き自由記述・任意)
3. 相談したい内容(自由記述)→ 月次で編集長が「具体的論点あり/なし」をタグ付け
4. 現在の状況(未受診/他院で治療中/治療済みで再相談)→ SO需要の把握

### 3.3 オフライン接点の計測

- 電話受付スクリプトに「何をご覧になってお電話いただけましたか」を追加し、予約システムに流入元フィールドを設ける
- 初診問診票に「キョウセイの前に(当院運営サイト)を読んだことがありますか/参考になった記事」を追加
- 初診カウンセリング後アンケートに理解度5段階質問を追加
- 月次で「フォーム経由+電話経由+問診票申告」を合算して記事経由相談数を確定する

### 3.4 その他データソース

- Search Console: 指名検索(ブランドクエリフィルタ)、記事別クエリ
- 引用モニタリングシート(06章6節)
- 予約システム: 相談→成約の突合(患者IDベース、個人情報は院内システムに閉じる。GA4に医療情報・個人情報を送らない)

## 4. 月次レポート様式(1枚)

1. 北極星: 記事経由の質の高い相談 __件(内訳: SO/難症例/一般、きっかけ記事Top3)
2. 成約: __件 / 成約率 __%(累計LTV概算)
3. ブランド: 指名検索 __(前月比)、AI引用 __/50クエリ
4. 中間: LINE __件、DL __件、完読率上位・下位記事
5. 供給: 公開 __本(累計__)、監修滞留 __本、コンプラ指摘 __件
6. 学び: FAQマイニングから来月の企画 __本
7. 判断事項: (あれば)

## 5. 投資判断ルール(感情を排した事前基準)

| 時点 | 継続条件(いずれかを満たす) | 満たさない場合 |
|---|---|---|
| 6か月 | 記事経由相談 累計5件+ / AI引用 5クエリ+ / 指名検索+20% | 記事ペースを月3本に落とし原因分析(コンテンツの質か、計測漏れか、受け皿か) |
| 9か月 | 相談 月3件+ かつ 成約1件以上 | 教育・B2B(Phase 3)への投資を凍結し、コア(難症例記事)のみ継続 |
| 12か月 | 成約累計5件+ or SO+講演等の直接収入が月次コストの30%+ | 縮小(月2本・維持モード)または撤退を経営会議で判断。**ゾンビ化(更新停止した医療サイトの放置)だけは選ばない** |
