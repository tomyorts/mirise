# 08 スタッフ向け操作マニュアル（MIRAI LINK）

このマニュアルは、院内スタッフが **MIRAI LINK（院内音声インカム）** を使うための手順書です。
むずかしい知識は不要です。

- **iPhoneアプリ**（おすすめ）: スマホはロックしてポケットに入れたまま、**服に付けた物理ボタン**（またはイヤホンのボタン）で話せます
- **PC（ブラウザ）**: 受付など、パソコンの前にいるスタッフ向け

---

## 1. 用意するもの

| | iPhoneアプリ | PC（ブラウザ） |
|---|---|---|
| 端末 | iPhone（**iOS 17以降**。ロック中にイヤホンのボタンで話すために必要） | パソコン（Chrome / Edge / Safari） |
| イヤホン | **ボタン付き・マイク付きのBluetoothイヤホン**（一般的なもの）<br>※ **AirPodsは使えません**（ボタンがインカム操作に使えないため） | マイク付きイヤホン / ヘッドセット |
| 物理ボタン（おすすめ） | **iTag型（紛失防止タグ）** または **Zello用PTTボタン**（→「3. 物理ボタンで話す」） | ― |
| その他 | アプリ（管理者がインストールします） | 医院の共通パスワード（管理者に確認） |

> Androidの方は **Android版アプリ**（管理者が配布）を使います。使い方はiPhoneとほぼ同じです（勤務中は通知欄に「MIRAI LINK 勤務中」が出ます）。
> アプリが配布されるまでは、PC版と同じURLをスマホのブラウザで開いて使ってください（画面を表示している間だけ使えます）。

---

## 2. iPhoneアプリの使い方

### 2-1. 出勤（はじめに1回）

1. アプリを開き、**スタッフ名**を入力（例: `佐藤` / `DH田中`）
   - 使える文字: 文字・数字・空白・「・」「_」「-」「.」（32文字まで）
2. **参加ルーム**を選ぶ（受付 / 診療室 / オペ / 滅菌 / 全体）
3. **「出勤する（接続）」**をタップ
4. 「マイクの使用を許可しますか?」→ **必ず「許可」**
5. 画面上部が **🟢「待機中 — イヤホンのボタンで話せます」**（物理ボタンを登録している場合は **🟢「待機中 — ボタンで話せます」**）になれば準備完了です
6. あとは **画面をロックしてポケットへ**。アプリを開き直す必要はありません

> 名前とルームは保存されるので、2回目からは「出勤する」を押すだけです。

### 2-2. 話す

> 💡 **物理ボタンがある場合は、そちらがおすすめです**（髪やマスクのひもでイヤホンのボタンが押しにくい問題がありません）。使い方は「3. 物理ボタンで話す」へ。

**イヤホンのボタンで話す**
- イヤホンのボタンを押す → **送信開始**、もう一度同じ押し方 → **送信終了**
  - 押し方はイヤホンの機種によって違います。多くの機種は **「2回押し（ダブルクリック）」** です
  - 最初に1回押し・2回押し・長押しを試して、送信が始まる押し方を覚えてください
- 押し忘れても **45秒で自動的に止まります**（マイクの付けっぱなし防止）
- スマホを取り出す必要も、画面を触る必要もありません
- ⚠️ **勤務中は音楽アプリを終了しておく**（再生中・一時停止中の音楽アプリがあると、イヤホンのボタンが音楽側に取られて送信できないことがあります）
  - 終了の仕方：画面下から上にスワイプして止める → 音楽アプリを上にスワイプ

**画面で話す**
- 画面の大きな **「押して話す」** ボタンを押している間だけ送信します
- 押すと「準備中…」→「話しています…（離すと終了）」に変わってから話してください

**イヤホンが無い時**
- 画面上部（Dynamic Island）やロック画面の **「MIRAI LINK」** 表示を開き、
  トークボタンを押している間だけ話せます

### 2-3. 聞く

- イヤホン接続中は、受信音は**イヤホンから**流れます（周囲には聞こえません）
- イヤホンが無い時は、**スピーカー**から鳴ります（ポケットの中でも聞こえるように）
  - 静かにしたい時は「🔊 イヤホン無しの時: スピーカーで鳴らす」をタップすると **受話口** に切り替わります
- 他のスタッフが話している間は、画面に「🗣 ○○ が話しています」と表示されます

### 2-4. 退勤

- **「退勤する（切断）」** を必ずタップしてください
- 退勤しないと、帰宅後もイヤホンのボタンで送信できる状態のままになります（退勤すると、物理ボタンを押しても送信されません）

---

## 3. 物理ボタンで話す（おすすめ）

服・名札・ポケットの口などに付けた **小さなBluetoothボタン** を押して話す方法です。
スマホは **ロックしたままポケットに入れておけます**。イヤホンのボタン（髪で隠れて押しにくい・機種によって押し方が違う）より確実なので、こちらをおすすめします。
Android版アプリ（配布されている場合）でも同じ手順で使えます。

### 3-1. 用意するボタン（買うもの）

| 種類 | 選び方の目安 | 話し方 |
|---|---|---|
| **iTag型（紛失防止タグ）** | 「iTag」「iSearching アプリ対応」と書かれた、ボタン付きの小さなタグ（通信方式 **FFE0**） | **押すたびにON/OFF**（30秒で自動停止） |
| **Zello用PTTボタン** | **PTT-Z01 / YPC21** など、名前が「PTT」で始まるもの | **押している間だけ話す**（押すたびにON/OFFにも切替可） |

**❌ 使えないもの（買わないでください）**
- **シャッターリモコン**（カメラ用）・**キーボード型リモコン**（プレゼン用のページめくり器・指輪型など）
  → 画面ロック中は反応しません（iPhoneの仕様。実機で確認済み）
- **Find My（「探す」）対応のタグ**（AirTag互換をうたうもの）
- **Tuya / Smart Life アプリ対応のタグ**（専用アプリ経由でしか動きません）

> 迷ったら「iSearching 対応の iTag」か「Zello 用 PTT ボタン（PTT-Z01）」を選んでください。

**実機（iPhone）で動作を確認済みの商品（2026年10月）** — Amazonの検索窓に商品番号を入れると出てきます

| 商品 | Amazon商品番号 | 値段の目安 | 確認したこと |
|---|---|---|---|
| Vbestlife Zello用ワイヤレスPTTボタン | B0CB8MN3XV | 約2,900円（電池CR2032は別売り） | ロック中に押している間だけ送信・60秒で自動停止・退勤後は送信されない |
| keptfit キーファインダー 3個入り（iTag） | B08L4LJS27 | 3個で約720〜1,400円 | ロック中（1分以上放置後）に押して開始・もう1回で停止・30秒で自動停止・Bluetoothオフ→オン後も使える |

> keptfit の iTag は「購読設定」を持たない安価な作りのため、アプリが **互換モード** で登録します（「詳細設定・診断」の物理ボタン欄に「互換モード（購読設定なし）」と出れば正常）。
> どちらも技適マークは確認できていません。業務で使う前に販売元へ技適番号を確認してください。

### 3-2. 登録する（はじめに1回）

1. アプリの **「🔘 物理ボタン」** の欄で **「ボタンを登録する」** をタップ（出勤前・退勤後でも登録・解除・テストができます）
   - iPhone:「Bluetoothの使用を許可しますか?」→ **「許可」**
   - Android:「付近のデバイス」（古い機種では「位置情報」）の許可 → **「許可」**
2. **ボタンの電源を入れる**（iTag型は「ピッ」と鳴るまで長押しすると電源が入ります）
3. ボタンを **スマホのそばに置き、画面をつけたまま** 待つ
4. 画面に **「ボタンを短く2回押してください」** と出たら、ボタンを **短く2回** 押す
   - 「1回目を確認しました。もう1回押してください」と出たら、もう1回
5. **「テスト中（残り10秒）」** と出たら登録完了です。そのまま **10秒間のテスト** になります
   - ボタンを押して **「反応しました ✅」** と出れば成功（テスト中は声は流れません）
   - あとからでも「テスト（10秒）」でいつでも確認できます
6. 欄の右上が **「準備完了」** になれば使えます

> - 登録は **ボタン1つずつ** 行ってください（近くにほかのタグがあると取り違えることがあります）
> - 登録したボタンは、そのスマホ専用です
> - 見つからない時は、ボタンをスマホにくっつけて、ボタンを1回押した直後にもう一度「ボタンを登録する」を押してください

### 3-3. 話す

| ボタンの種類・押し方の設定 | 話し方 | 止め忘れ防止 |
|---|---|---|
| iTag型（いつもこれ） | 1回押す → **送信開始**、もう1回押す → **終了** | **30秒** で自動停止 |
| PTTボタン型「押している間だけ話す」（初期設定） | **押している間だけ** 送信、離すと終了 | 押しっぱなしでも **60秒** で自動停止 |
| PTTボタン型「押すたびにON/OFF（30秒で自動停止）」 | iTag型と同じ | **30秒** で自動停止 |

- PTTボタン型の押し方は、「物理ボタン」の欄の **「押し方」** で切り替えられます
- ボタンがしばらく使われず眠っていた時は、最初の1回で「つなぎ直し」だけが行われ、送信されないことがあります。**反応が無ければ、もう一度押してください**
- 画面上部が **🔴送信中** の間は、同じルームの全員に聞こえています

### 3-4. 勤務中に守ること

- 🚫 **アプリを上にスワイプして終了しない**（ボタンが反応しなくなります）
- 🚫 **Bluetoothをオフにしない**（コントロールセンターや機内モードでも切れます）
- 🔁 **スマホを再起動したら、一度アプリを開く**（開くまでボタンがつながりません）
- 🚫 **iTag型は長押ししない**（3〜5秒押し続けると電源が切れます。切れたら「ピッ」と鳴るまで長押しして入れ直す）
- 🔋 反応が悪くなったら **ボタンの電池**（多くはボタン電池 CR2032）を交換

### 3-5. 登録を解除する / ボタンを替える

- 「物理ボタン」の欄の **「登録を解除」** → 確認画面で **「解除する」**
- 新しいボタンは、解除のあと「ボタンを登録する」から登録し直します
- アプリの更新後に **「ボタンの登録情報が古い形式です」** と出たら、一度「登録を解除」してから登録し直してください

## 4. PC（ブラウザ）の使い方

1. ブラウザで次のURLを開き、**医院の共通パスワード**でログイン（約12時間有効）

   ```
   https://mirisevoicelink.vercel.app
   ```

2. **スタッフ名**（必須）と **参加ルーム** を選び、**「接続する」**
3. 「マイクの使用を許可しますか?」→ **「許可」**
4. 話し方は2通りです
   - **押して話す**: 大きなボタン（またはキーボードの **スペースキー**）を**押している間だけ**送信（押し続けても60秒で停止）
   - **タップで送信**: 1回押すと送信開始、もう1回で停止（止め忘れても**30秒で自動停止**）
5. 送信中は画面上部に**赤く表示**されます。**別のウィンドウ・タブに切り替えると送信は止まります**
6. 終わる時は **「切断する」**。共有PCの場合は **「ログアウト」** も押してください

> マイクが無い・許可されていないPCでも、**聞くだけ**の状態で接続できます。

### 緊急呼び出し（PC）

- **「緊急：全体ルームで呼び出す」** を押すと、このPCが「全体」ルームに移り、通知を送って **8秒間マイクがON** になります
- 声が届くのは、**その時点で「全体」ルームに接続している端末だけ**です。**緊急時のみ**使ってください

## 5. 会話のルール（重要・医療機関として厳守）

- 🚫 **患者様の氏名・個人情報を声に乗せない**
  - ×「田中様が受付に」 → ○「**チェア3番**の準備お願いします」「**アポ枠2番**ご案内です」
- 🚫 録音・録画はしない（アプリにも録音機能はありません）
- 🎧 診療室ではイヤホンを使う（スピーカーだと患者様に聞こえます／ハウリングします）
- 🔴 送信中（赤い表示）は、同じルームの全員に聞こえています。終わったら必ず止める

## 6. よくあるトラブル

| 症状 | 対処 |
|---|---|
| イヤホンのボタンを押しても送信されない | アプリを開いて画面上部の表示を確認 →「⚠️ 今はロック中・ポケットの中から話せません」が出ていたら「ロック中でも話せるようにする」をタップ。直らなければ「退勤する」→「出勤する」 |
| AirPodsのボタンで話せない | AirPodsは非対応です。一般的なBluetoothイヤホンを使ってください |
| 物理ボタンを押しても送信されない | アプリを開いて「物理ボタン」の欄を確認。「再接続待ち」ならボタンを1回押して少し待つ／「Bluetoothオフ」ならBluetoothをオン／「⚠️ …ボタンで話すには…」の案内が出ていれば、そのとおりにタップ。もう一度押しても反応しない時は「テスト（10秒）」で反応を確認 |
| 「ボタンの信号が多すぎるため、30秒間…」と出る | 押しっぱなし・故障の可能性があるため、30秒間ボタンを止めています。30秒たつと戻ります。何度も出る場合はボタンを交換してください |
| 物理ボタンが登録できない（見つからない） | ボタンの電源を確認し、スマホにくっつけて1回押した直後に「ボタンを登録する」。シャッターリモコン・キーボード型・Find My対応・Tuya対応のタグは使えません |
| 物理ボタンが急に反応しなくなった | iTag型を長押しして電源が切れた可能性があります。「ピッ」と鳴るまで長押しして電源を入れ、アプリを一度開いてください |
| イヤホンのボタンで音楽が流れる | 音楽アプリを終了してから「退勤する」→「出勤する」。それでも続く場合は別のイヤホンを試してください |
| 「マイクの使用が許可されていません」 | 表示される「設定を開く」→「マイク」をオン |
| 「通信が途切れました」 | 電波の届く場所に戻ると自動で再接続します。アプリを開くか、イヤホンのボタンを押しても再接続します |
| 「同じ端末の別の接続に切り替わったため切断されました」 | 同じ端末で二重に接続した時に出ます。「再接続する」を押してください |
| 「サーバーから応答がありません」 | 電波の弱い場所か、Wi-Fiがインターネットに繋がっていない可能性があります。場所を変えて再試行 |
| 声が聞こえない | イヤホンの接続を確認 →「退勤する」→「出勤する」で再接続 |
| ログインできない（PC） | パスワードを管理者に確認（大文字小文字も正確に） |
| キーンと音が鳴る | ハウリングです。イヤホンを着けるか、近くの端末と距離を取ってください |

困ったら管理者（またはICT担当）へ連絡してください。
アプリの不具合を報告する時は、アプリの「詳細設定・診断」→「診断ログ」の画面をスクリーンショットで送ってください。
