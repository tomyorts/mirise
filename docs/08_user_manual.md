# 08 スタッフ向け操作マニュアル（MIRISE Intercom）

このマニュアルは、院内スタッフが **MIRISE Intercom（院内音声インカム）** を使うための手順書です。
むずかしい知識は不要です。

- **iPhoneアプリ**（おすすめ）: スマホはポケットに入れたまま、**イヤホンのボタンだけで話せます**
- **PC（ブラウザ）**: 受付など、パソコンの前にいるスタッフ向け

---

## 1. 用意するもの

| | iPhoneアプリ | PC（ブラウザ） |
|---|---|---|
| 端末 | iPhone（**iOS 17以降**。ロック中にイヤホンのボタンで話すために必要） | パソコン（Chrome / Edge / Safari） |
| イヤホン | **ボタン付き・マイク付きのBluetoothイヤホン**（一般的なもの）<br>※ **AirPodsは使えません**（ボタンがインカム操作に使えないため） | マイク付きイヤホン / ヘッドセット |
| その他 | アプリ（管理者がインストールします） | 医院の共通パスワード（管理者に確認） |

> Androidの方は、当面はPC版と同じURLをスマホのブラウザで開いて使ってください（画面を表示している間だけ使えます）。

---

## 2. iPhoneアプリの使い方

### 2-1. 出勤（はじめに1回）

1. アプリを開き、**スタッフ名**を入力（例: `佐藤` / `DH田中`）
   - 使える文字: 文字・数字・空白・「・」「_」「-」「.」（32文字まで）
2. **参加ルーム**を選ぶ（受付 / 診療室 / オペ / 滅菌 / 全体）
3. **「出勤する（接続）」**をタップ
4. 「マイクの使用を許可しますか?」→ **必ず「許可」**
5. 画面上部が **🟢「待機中 — イヤホンのボタンで話せます」** になれば準備完了です
6. あとは **画面をロックしてポケットへ**。アプリを開き直す必要はありません

> 名前とルームは保存されるので、2回目からは「出勤する」を押すだけです。

### 2-2. 話す

**イヤホンのボタンで話す（基本）**
- イヤホンのボタンを **1回押す → 送信開始**、**もう1回押す → 送信終了**
- 押し忘れても **45秒で自動的に止まります**（マイクの付けっぱなし防止）
- スマホを取り出す必要も、画面を触る必要もありません
- ※ 機種によっては、押した時に音楽アプリも反応することがあります

**画面で話す**
- 画面の大きな **「押して話す」** ボタンを押している間だけ送信します
- 押すと「準備中…」→「話しています…（離すと終了）」に変わってから話してください

**イヤホンが無い時**
- 画面上部（Dynamic Island）やロック画面の **「MIRISE Intercom」** 表示を開き、
  トークボタンを押している間だけ話せます

### 2-3. 聞く

- イヤホン接続中は、受信音は**イヤホンから**流れます（周囲には聞こえません）
- イヤホンが無い時は、**スピーカー**から鳴ります（ポケットの中でも聞こえるように）
  - 静かにしたい時は「🔊 イヤホン無しの時: スピーカーで鳴らす」をタップすると **受話口** に切り替わります
- 他のスタッフが話している間は、画面に「🗣 ○○ が話しています」と表示されます

### 2-4. 退勤

- **「退勤する（切断）」** を必ずタップしてください
- 退勤しないと、帰宅後もイヤホンのボタンで送信できる状態のままになります

---

## 3. PC（ブラウザ）の使い方

1. ブラウザで次のURLを開き、**医院の共通パスワード**でログイン（約12時間有効）

   ```
   https://mirisevoicelink.vercel.app
   ```

2. **スタッフ名**（必須）と **参加ルーム** を選び、**「接続する」**
3. 「マイクの使用を許可しますか?」→ **「許可」**
4. 話し方は2通りです
   - **押して話す**: 大きなボタン（またはキーボードの **スペースキー**）を**押している間だけ**送信（押し続けても60秒で停止）
   - **タップで送信**: 1回押すと送信開始、もう1回で停止（止め忘れても**30秒で自動停止**）
5. 送信中は画面上部に**赤く表示**されます。**別のウィンドウ・タブに切り替えると送信は止まります**
6. 終わる時は **「切断する」**。共有PCの場合は **「ログアウト」** も押してください

> マイクが無い・許可されていないPCでも、**聞くだけ**の状態で接続できます。

### 緊急呼び出し（PC）

- **「緊急：全体ルームで呼び出す」** を押すと、このPCが「全体」ルームに移り、通知を送って **8秒間マイクがON** になります
- 声が届くのは、**その時点で「全体」ルームに接続している端末だけ**です。**緊急時のみ**使ってください

---

## 4. 会話のルール（重要・医療機関として厳守）

- 🚫 **患者様の氏名・個人情報を声に乗せない**
  - ×「田中様が受付に」 → ○「**チェア3番**の準備お願いします」「**アポ枠2番**ご案内です」
- 🚫 録音・録画はしない（アプリにも録音機能はありません）
- 🎧 診療室ではイヤホンを使う（スピーカーだと患者様に聞こえます／ハウリングします）
- 🔴 送信中（赤い表示）は、同じルームの全員に聞こえています。終わったら必ず止める

---

## 5. よくあるトラブル

| 症状 | 対処 |
|---|---|
| イヤホンのボタンを押しても送信されない | アプリを開いて画面上部の表示を確認 →「⚠️ 今はロック中・ポケットの中から話せません」が出ていたら「ロック中でも話せるようにする」をタップ。直らなければ「退勤する」→「出勤する」 |
| AirPodsのボタンで話せない | AirPodsは非対応です。一般的なBluetoothイヤホンを使ってください |
| イヤホンのボタンで音楽が流れる | 機種によって起こります。気になる場合は別のイヤホンを試してください |
| 「マイクの使用が許可されていません」 | 表示される「設定を開く」→「マイク」をオン |
| 「通信が途切れました」 | 電波の届く場所に戻ると自動で再接続します。アプリを開くか、イヤホンのボタンを押しても再接続します |
| 「同じ端末の別の接続に切り替わったため切断されました」 | 同じ端末で二重に接続した時に出ます。「再接続する」を押してください |
| 「サーバーから応答がありません」 | 電波の弱い場所か、Wi-Fiがインターネットに繋がっていない可能性があります。場所を変えて再試行 |
| 声が聞こえない | イヤホンの接続を確認 →「退勤する」→「出勤する」で再接続 |
| ログインできない（PC） | パスワードを管理者に確認（大文字小文字も正確に） |
| キーンと音が鳴る | ハウリングです。イヤホンを着けるか、近くの端末と距離を取ってください |

困ったら管理者（またはICT担当）へ連絡してください。
アプリの不具合を報告する時は、アプリの「詳細設定・診断」→「診断ログ」の画面をスクリーンショットで送ってください。
